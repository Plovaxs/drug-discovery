Two limits of this provenance record are stated rather than left for a reader to discover. First, redistribution: this thesis does not restate the licence terms of CrossDocked2020, BindingNet or the PDB-derived structures it builds on, because those terms were not independently verified during this work, and a reproducer must consult each source's own terms before redistributing any derived artefact. The scripts and the split definitions in this repository are the author's own; the underlying data are not. Second, scale: the pocket-cropped LMDB alone is 3.8 GB, and regenerating it requires the upstream CrossDocked2020 download, so an end-to-end reproduction from raw data is a substantial undertaking rather than a single command. A reproducer wanting to check a specific number rather than the whole pipeline is better served by the per-result scripts named throughout this appendix, each of which reads a cached intermediate and runs in seconds to minutes.

@sec Test-Set Isolation, Per Training Run

A reader has to be able to check, without taking the author's word for it, that the held-out test set did not participate in choosing any model reported here. {tab:sealed} states for each family of training runs what the checkpoint was selected on and whether the test set was evaluated at all during training, with the evidence that establishes it. Two distinctions matter and are kept separate in the table, because conflating them is how this kind of claim usually goes wrong. *Selection* means the quantity whose improvement caused a checkpoint to be kept or training to continue; in every trainer used here that quantity is the validation loss, which is read directly from the code (`best_val_loss` drives both checkpoint retention and early stopping in `train_egnn_stage0.py` and `train_surrogate_arm.py`). *Exposure* means whether the test set was evaluated at all, even only to write a number into a log. Exposure without selection does not invalidate a result, but it is weaker than no exposure, so it is reported rather than glossed.

@sec Reproducing the Results and This Document

The result of a stage can be recomputed from the stored raw files. For example, the Track E gate results were produced by the analysis script of `guidance/track_e/` from the per-run test predictions, with the bootstrap seed 20260925, and were written to `guidance/track_e/e1_gate_results.json`. The Track E stages are run with `guidance/run_track_e.sh run --stage e1`, which can be interrupted and resumed at any time. Sampling and docking jobs of Tracks A to D wrote one result directory per (condition, pocket, seed) unit and skip units that are complete. The figures of this document are generated by `guidance/thesis/make_figures.py` from the result files, and the document is assembled by `guidance/thesis/build_thesis.py`, which writes the Word file and computes the page numbers of the tables of contents from a PDF rendering. The values reported in the text were re-derived from the raw result files; where an earlier finding document contained a different value, the raw file was used and the discrepancy is noted in the text.

@sub Checking that the stored results still follow from the code

Being able to recompute a result is not the same as having checked that the stored result still matches what the code produces. Nothing else in this project closes that gap. The number checker described earlier in this appendix verifies that this document agrees with the committed result files; it cannot tell whether a result file still agrees with the script that claims to have produced it. A script edited after its output was written, a dependency whose default changed, or an output left behind by an exploratory run would all pass every other check here and leave a thesis whose numbers no longer regenerate.

`guidance/verify_results_reproduce.py` closes it for the analyses where closing it is affordable. It re-runs each seeded, CPU-only analysis, captures the fresh output, restores the committed file, and compares the two field by field at a relative tolerance of 10⁻⁹. The restore happens in a `finally` block, so an interrupted run cannot leave a regenerated file standing in the repository in place of the committed one. Seven analyses are covered, comprising 1,038 individual values: the representation ladder, the noise-ceiling decomposition, the activity-cliff and matched-molecular-pair analyses, the protein-family stratification, the clustering-level check of Chapter III and the residual-variance audit of Chapter IV. All seven now reproduce exactly.

The scope of that statement is narrower than "this thesis reproduces", and the difference is stated rather than left to be assumed. GPU training runs and diffusion sampling runs are not covered. They are not bit-reproducible at this precision even at a fixed seed, a property measured directly rather than assumed and reported with the trajectory traces of Appendix E, and re-running them is hours of compute on the hardware described in Section A.1. No claim is made that they reproduce bit for bit.

The check earned its place on its first run. Six of the seven analyses reproduced; the protein-family stratification did not. Its committed result file carried bootstrap p-values of 0.600 and 0.200, values only reachable from a handful of resamples, while the script's default and the protocol of Section III.6 both specify 2,000. The stored artefact was the output of an early low-resample run that a later full run had never overwritten. The numbers quoted in the protein-family paragraph of Chapter IV were, as it happens, the correct 2,000-resample ones, so no reported result was wrong; but a reader who recomputed from the stored file would have obtained different intervals from the ones printed here, and nothing in the project would have detected a subsequent drift, because those values had never been pinned. The artefact was regenerated, one rounding error in the quoted lower bound was corrected (−0.2645 had been printed as −0.264), and the seven affected values were added to the pinned set. This is recorded here rather than quietly fixed, because the failure mode it illustrates, a stale artefact that is valid in form and wrong in content, is the one a reproducibility check exists to catch.

@appendix B | LITERATURE SEARCH AND VERIFICATION

@sec Search Strategy

The literature was collected in two phases. In the first phase, related work on generative structure-based drug design, guidance of diffusion models, learned scoring functions, docking biases and data leakage was collected while the experiments were designed. In the second phase, before the delta-learning experiment, a structured review of 45 sources was made for the two ideas that motivated it (residual learning against a physics-based baseline, and interaction-typed auxiliary supervision), together with the nearest published combinations. Searches used bibliographic databases and a research-paper search service with queries on delta-learning, multi-task learning with interaction labels, interaction-conditioned diffusion, classifier guidance for molecular generation, and leakage-controlled benchmarks. An independent check of 12 papers, supplied during the work, was used to revise the novelty statement.

@sec Verification and Its Limits

The bibliographic details of the references were verified in different ways. For most entries, the record in PubMed was retrieved and the authors, journal, volume, pages and identifier were compared with the entry. For sources that are not indexed there (conference papers and preprints), the document itself was consulted. A final pass checked the five most recently added references against the Crossref registry, and the preprint among them against its arXiv record, comparing title, author list, venue, volume, pages and DOI field by field.

That final pass is reported here rather than quietly absorbed, because it changed three entries and two of the changes were substantive. The preprint BoKDiff had been entered with a reconstructed title and a wrong first-author initial; both are corrected to the record ("BoKDiff: Best-of-K diffusion alignment for target-specific 3D molecule generation", A. Khodabandeh Yalabadi *et al.*), and its "first to apply Best-of-K alignment and Best-of-N sampling to SBDD" claim, on which the narrowing of this thesis's own positive-control novelty in Section VI.5 depends, was confirmed verbatim in the abstract. The Kwapien *et al.* entry had carried an unresolved venue ("ACS Omega / J. Chem. Inf. Model."); it is ACS Omega, vol. 7, no. 30. The remaining three were confirmed exactly as entered, and DOIs were added to all five. The lesson is the obvious one and is recorded because this thesis argues elsewhere that checks are worth their cost: a reconstructed citation is a hypothesis about a document, and two of five such hypotheses here were wrong in a way only a registry lookup would reveal. Quotations attributed to a source were checked in the text of the source. Statements about what a paper reports are limited to what could be read: where only an abstract was available, the statement is limited to the abstract, and where a paper could not be read in full (PLANET, and the training loss of DiffInt), no statement about its full content is made.

A targeted re-check was run at revision time against the single novelty claim with the largest load-bearing role in Chapter IV, the within-target label-permutation decomposition of apparent performance into a class-level prior and a within-target structure–activity component. Two searches, phrased once around the permutation control itself and once around the equivalent baseline a reader might expect it to be called (a per-target mean or target-stratified baseline on PDBbind-style data), did not return a study applying that control to protein–ligand affinity prediction; the claim is therefore left standing, in the "we did not find" form used throughout. The same check did surface contemporaneous work reaching a compatible conclusion by a different method, MIRAGE [@mirage2026], which is now cited in Section II.4 and discussed in Section IV.8 as convergence rather than precedence, since it was released while this thesis was being written and measures family support rather than within-target signal. Recording this is the point of the exercise: a novelty claim that survives a directed attempt to refute it is worth more than one that was never tested, and the attempt is documented here so that a reader can repeat it.

The search has limits that bear on the wording of novelty. It was made with the tools available, it did not include a manual search of Google Scholar or Semantic Scholar, it covers work up to the date of the review, and the absence of a study in the results of these searches is not proof that no such study exists. Consequently the claim of Section VIII.8 is formulated as "we did not find". A similar limit applies to Chapter II as a whole: it is a focused review of the literature closest to the experiments, and not a systematic review.

@appendix E | POST-SYNTHESIS FOLLOW-UP: TESTING THE DIAGNOSED MECHANISM DIRECTLY

This appendix is, in the terms of Section III.1.1, an *Appendix E follow-up*: every analysis below was conducted after Chapter IX's synthesis had already been written and frozen, and none of it was pre-registered. It is not part of the decision sequence of Tracks A to E (Chapters IV to VIII), it was not subject to the standing two-independent-routes rule or to any frozen stopping rule, and no verdict here revises a verdict already reached in Chapters IV to X. It follows this project's general exploratory-then-confirmatory working discipline (Section III.6.1) and the same corrected-statistics standard as the rest of the thesis, but its status is additional evidence for the main synthesis, not a continuation of the main synthesis's own pre-declared design.

@sec Scope and Relation to the Main Synthesis

Chapter IX's "Grading the explanations" (Section IX.2.3) listed four hypotheses that were consistent with the measured evidence but not tested: (a) that the mismatch between clean training poses and noisy intermediate diffusion states makes the gradient unreliable; (b) that the evaluation target (Vina) and the training target (experimental affinity) ask different questions; (c) that position-only guidance, with the atom-type gradient set to zero and no gradient path through the denoiser, is too weak or too blunt an intervention; and (d) that a smooth 3D gradient is a poor way to steer a fingerprint-based synthesizability target. After that synthesis was written, 8 further checkpoints were independently trained and tested to address hypotheses (a) and (c) directly, together with two closely related questions raised by the main result: whether the null pattern survives independent, chemistry-level validation (not just a docking score) and the hardest train/test separation this project can construct, and what happens, mechanistically, to a single molecule's atoms when the gradient is actually applied step by step. This appendix reports that work in full. It changes none of Chapter IX's conclusions; it deepens the evidence for them and resolves, where possible, which of the untested hypotheses the new evidence favours.

The 8 checkpoints are organised in three phases, following the order in which they were run. Phase 1 (E.2) varies the predictor's training recipe and representation directly, taking the diagnostic in Section V.4 as a training target or adding a genuinely new information source. Phase 2 (E.3) tests the resulting null pattern under independent, non-docking validation and under the strictest generalisation split available. Phase 3 (E.4) sharpens one of Phase 1's representations and independently cross-checks the project's affinity labels. Section E.5 reports the mechanistic trace that answers hypothesis (c) directly, at the level of one molecule's atoms, step by step. Section E.6 pools every independently computed docking comparison of this appendix with the pool of Chapter IX into a single correction. All checkpoints were trained on the same leakage-safe split as Chapter IV (Section III.3), and every independently computed docking test reuses the KS-test and Wilcoxon-signed-rank protocols of Section III.6.1 unless stated otherwise.

It previews a pattern this appendix establishes in detail: several follow-up branches reach a higher directional consistency than any original thesis track except the Track C ranker, and the Track C ranker's own 93% is the one case already shown (Chapter VI) to be a measurement artefact of molecular size rather than a real effect, not a benchmark the other routes are falling short of.

@sub Noise-matched and Vina-derived training recipes

Hypothesis (a) was tested directly: a noise-matched curriculum trains the Stage 0 EGNN predictor on ligand positions corrupted by the same forward-diffusion schedule it will see at inference (t ~ Uniform(0, 500)) instead of on clean docked poses only. A second, independent change (the "Vina-target" recipe) replaces the heterogeneous experimental pK label with a Vina-derived anchor, so the predictor's training target matches the evaluation metric, testing hypothesis (b) at the same time. Both recipes were trained on the EGNN backbone and, together, on the physics-anchored GIGN+PIGNet2 backbone of Track A (Section V.2), to ask whether a null pattern specific to the original training recipe might behave differently under a recipe suggested by the diagnosed mechanism itself.

Neither recipe changed the outcome. On the EGNN backbone, a paired Wilcoxon signed-rank test against the unguided baseline (n = 8 molecules per condition, three non-zero λ each) gave no p-value below 0.10 for either recipe (noise-matched: p = 0.156 / 0.250 / 0.312 at λ = 0.1 / 1.0 / 10.0; Vina-target: p = 0.312 / 0.102 / 0.945), with mean shifts no larger than 0.14 kcal/mol in either direction. On GIGN+PIGNet2, both recipes applied together and tested like-for-like against the original Track A protocol (8 pockets, n = 30 molecules per condition, independent Vina Dock and PoseBusters) gave 0/16 comparisons significant after Benjamini–Hochberg correction [@benjamini1995] (minimum raw p = 0.031, minimum corrected p = 0.489), a result reported in full in {tab:fupool}. The one notable surface change was the correct-direction rate: 14 of 16 comparisons (87.5%) pointed the expected way, the highest rate of any checkpoint in this investigation, including the original Track A checkpoint's 67%. PoseBusters validity degraded in 9 of 16 conditions (56%), concentrated at the higher of the two tested strengths. The directional improvement did not translate into a single significant, corrected effect; this is the pattern that recurs through the rest of this appendix.

@sub Kitchen-sink: all four interventions combined

The one combination not yet tried among Phase 1's own four interventions stacks all of them (noise-matched curriculum, Vina-target label, gradient-alignment loss, ESM2 feature) in one checkpoint, run to ask whether any pair of them might interact rather than because a specific mechanism predicted synergy. Predictive quality (R² = 0.413, Pearson = 0.664, Spearman = 0.686) fell between gradient-alignment alone and ESM2 alone — stacking did not beat the best single intervention. A visible overfitting signature appeared once four objectives were optimised jointly (validation R² briefly went negative at epoch 3 before the best checkpoint was recovered at epoch 2), not present in any single-intervention checkpoint at the same training budget. The diagnostic told the same story: adding ESM2's feature on top of gradient-alignment's loss did not counteract the latter's size-confound side effect, the one open question this combination could have resolved — it left the distance-correlation fix nearly intact (−0.757, against gradient-alignment alone's −0.784) while making the size/heaviness correlation slightly worse (+0.354, now the worst of any checkpoint). The independently computed docking test (prelambda check, n = 8, full seven-point grid) showed no encouraging direction at any λ, small and inconsistently signed diffs, worst at the highest strength rather than any dose-response; structural validity, notably, never degraded even out to λ = 30, the only checkpoint in this appendix for which that holds. This closes the ablation space of Phase 1 cleanly: no single intervention, pair, or full combination of the four tried (noise-matching, Vina-target, gradient-alignment, ESM2) produces an independently computed docking effect that survives correction. {fig:fudiag} shows this dissociation between diagnostic quality and docking outcome across every checkpoint of Phase 1 at once.

@sec Phase 2: Independent Validation and the Hardest Generalisation Test

@sub Does guidance change chemically meaningful interactions, not just the raw score? (PLIP)

Every independently computed docking test to this point asks whether the raw Vina Dock score moves. A different, closely related question is whether guidance changes the number of geometrically detected, chemically meaningful protein–ligand interactions a pose actually forms — hydrogen bonds, hydrophobic contacts, π-stacking and salt bridges, counted by the Protein–Ligand Interaction Profiler (PLIP) [@salentin2015; @adasme2021] on the same Vina-docked poses used throughout this appendix. This matters specifically against one alternative explanation for the overall null pattern: that Vina Dock is a misleading proxy hiding an interaction-level improvement a score-only metric cannot see.

An exploratory tier on the ESM2 checkpoint (n = 8, λ = 3.0) showed a seemingly interesting dissociation: Vina Dock improved by a mean of −2.27 kcal/mol (raw p = 0.031) while PLIP-detected interactions decreased by a mean of −3.71 (p = 0.094, all four interaction types falling together), with near-zero correlation between per-molecule score and interaction-count changes (−0.02 to −0.13) — a "chemically hollow" score gain, on its face. Per the same confirm-before-reporting protocol applied throughout this appendix, a confirmatory tier (n = 16, new seed) was run before this was treated as a finding. The signal did not merely weaken; it reversed sign ({fig:fuplip}): interactions changed from −3.71 to +1.00, and the Vina Dock shift itself weakened to −1.02 kcal/mol (p = 0.077, no longer below 0.05). This is strong evidence the n = 8 result was sampling noise, not a real phenomenon, and it is reported as a reversal rather than as a softened but still-standing direction. A second checkpoint with the opposite diagnostic profile (gradient-alignment, the strongest distance-correlation fix and the flattest independently computed docking result) showed the same null at both the score and the interaction level (n = 8, λ ∈ {1.0, 10.0}, no comparison significant in either direction). Neither checkpoint tested — the one that came closest to a defensible docking effect, or the one with the strongest mechanistic fix — shows a defensible chemistry-level guidance effect in either direction. This result is reported on its own terms and is not pooled into Section E.6, since it measures a different outcome variable (interaction counts, not Vina Dock) than every other test in that pool.

What a count of detected interactions can support is also narrower than the phrase "chemistry-level effect" might suggest, and the limit applies symmetrically to both directions of this result. PLIP applies geometric and chemical criteria to a pose and returns the contacts that satisfy them; the number it returns can rise because a molecule genuinely makes more favourable contacts, but equally because it grew, because an atom drifted inside a distance cut-off, or because a pose shifted in a way that satisfies an angular criterion without improving binding. A rise is therefore not evidence of improved affinity, and a fall is not evidence of the reverse. The count was used here as an *orthogonal-outcome* check, a quantity that moves on different grounds from Vina Dock and so would corroborate a docking effect if it moved with one, and not as a measure of binding in its own right. No claim in this thesis rests on an interaction count alone.

@fig fuplip | guidance/followup_figures/fig9_plip_signal_reversal.png | 4.6 | PLIP-detected interaction-count shift under guidance on the ESM2 checkpoint, exploratory tier (n=8) against confirmatory tier (n=16, new seed). The sign of the effect reverses, not merely weakens, between the two tiers.

@sub Generalisation to a protein family never seen in training

The leakage-safe split of Chapter IV separates test targets from training targets by protein identity, but still allows a test target to share a fold or family with something the predictor saw during training. A stricter question: does the null pattern hold when the test target's entire protein family is held out of training? PF00069, the protein kinase domain and the single largest family in the split's own Pfam annotations [@mistry2021], was removed entirely — 53 targets (8,880 entries) moved to test, with no kinase-family target appearing anywhere in training or validation. The scope of what this can establish should be fixed before its result is read: one family was held out, not many, so the correct reading is "the null survives the hardest *single-family* generalisation test available in this split", not that the predictor is robust out of distribution across the proteome. Kinases are also an unusually well-populated and internally homogeneous family, which makes them the most favourable case for a model that has learned family-level regularities and the most demanding one for a model that has not; a family chosen for being small or structurally heterogeneous could behave differently. Repeating this with several held-out families, which this project did not have the compute budget to do, is the obvious strengthening.

Point-prediction quality did not collapse on the unseen family; if anything it was somewhat better than the same-distribution checkpoint's own numbers (R² = 0.507, Pearson = 0.713, Spearman = 0.755, against the familiar-distribution Vina-target checkpoint's 0.400 / 0.652; {tab:fuquality}, {fig:fufamily}). The diagnostic was healthier too, and for the first time on a non-forced checkpoint reached significance in the correct direction without any auxiliary loss asking it to: −0.086 (95% CI [−0.136, −0.037]), against the familiar-distribution checkpoint's wrongly signed +0.047 ({tab:fudiag}). The independently computed docking test, run on CDK6_HUMAN (a major real-world kinase drug target and a member of the held-out family, prelambda check, n = 8, full grid), showed no significant effect at any λ (Wilcoxon p = 0.195 to 0.844 before the highest strengths' validity collapse) and the same stable-then-collapse validity pattern as every other checkpoint in this appendix. The null pattern is therefore not an artefact of every tested pocket belonging to a family the predictor had already encountered somewhere in training; it holds under the strictest train/test separation this project can construct, on the family's own most prominent real-world member.

@sec Phase 3: Sharpening the Representation and an Independent Label Check

@sub A pocket-restricted protein-language-model feature

Phase 1's ESM2 feature pools the embedding over the entire protein chain, a coarse signal relative to the handful of residues that actually line the binding site. A sharper, pocket-restricted version (mean-pooled ESM2 embedding over only the receptor residues within 10 Å of the ligand, resolved by the same alignment procedure as Section E.3.3, 847/971 targets, 87% coverage) tests whether sharpening this signal helps either predictive quality or the independently computed docking outcome.

It did not help either, and on predictive quality it clearly hurt: test R² fell from 0.460 (whole-protein) to 0.280, with Pearson and Spearman both falling slightly as well (0.731 → 0.686; 0.748 → 0.723; {tab:fuquality}). Restricting ESM2's mean-pooling to a handful of pocket residues (typically 3 to 60 per target, far fewer than a full chain of hundreds) produced a noisier, less accurate predictor than pooling over the whole protein — a plausible but unverified explanation is that mean-pooling over so few residues gives a much higher-variance per-target estimate than averaging a full chain. Two things change at once between these arms, and the comparison cannot separate them: *which* residues are represented (pocket versus whole chain) and *how* their embeddings are reduced to a fixed vector (a mean over 3–60 vectors versus a mean over hundreds). The result therefore bounds this particular pocket-restricted integration, not the value of pocket-local protein-language-model features in general; an arm that kept the residue selection but replaced mean-pooling with an attention or set-based reduction, at the same backbone and training budget, would be needed to attribute the loss to either factor. It is reported as a negative result for the variant tried. The diagnostic was healthy but did not improve on the whole-protein version: the distance correlation kept the correct sign but lost significance (−0.026, 95% CI [−0.069, 0.017], against the whole-protein version's significant −0.072; {tab:fudiag}). The independently computed docking test (prelambda check, n = 8, full grid) showed a mean effect that grew monotonically with λ up to 3.0, non-significant throughout (p = 0.148 to 0.945), reaching its closest approach to significance (p = 0.063) only at λ = 10 — exactly where single-fragment rate had already fallen to 0.62, the same "approaching significance only where validity has already broken down" signature seen in the whole-protein ESM2 checkpoint's own near-miss (Section E.2.3). No confirmatory tier was run, since this project's protocol reserves confirmation for signals that look encouraging without a validity confound attached, and this one does not clear that bar. This is also the first checkpoint in this appendix to make predictive quality actively worse than its own predecessor by trying to sharpen a signal, rather than add a new one.

@sub Was CD38 a pattern or a one-off? An expanded sample

The four-target check above is not a sample; the targets were chosen because they recur throughout this appendix, and four points cannot say whether the one disagreement found (CD38) is a pattern or a one-off. A further 20 targets were drawn by seeded random sampling from the 127-target leakage-safe test set of Chapter IV (seed 20261016, `guidance/chembl_f051_sample.py`) and checked the same way: this project's own pK range for the target against ChEMBL's independently curated Ki range, retrieved 2026-10-16, via the bio-research ChEMBL MCP connector (activity_type=Ki, unit=nM).

Of the 20 targets drawn, 3 could not be mapped to a single ChEMBL target with confidence and were excluded rather than guessed at: one carried an organism code this check could not resolve to a specific species without risking a cross-species mismatch, and two returned no plausible ChEMBL target at all under a gene-symbol or name search. Of the 17 that resolved, 4 have no Ki-type measurement in ChEMBL at all, which is itself a finding about coverage rather than a failure of this check: ChEMBL's curation of some targets, such as a lectin typically assayed by fluorescence polarisation rather than classical binding, or targets with little medicinal-chemistry history, is sparse for the specific activity type (Ki) this comparison requires, independent of whether the target is well studied by other measures.

Of the 13 targets with ChEMBL Ki data, 12 of 13 show this project's pK range overlapping ChEMBL's independently curated range. CD38 is not a one-off: a second, independent disagreement of the same shape appears in RNAS2 (non-secretory ribonuclease / RNase 2), where this project's labels are uniformly weak (pK 4.24–4.49, n = 6) while ChEMBL's only two Ki entries for this target, from the same published inhibitor series, are both sub-micromolar (pChEMBL 6.75), shown in {fig:chemblexp}. The explanation proposed for CD38 fits here too and is strengthened by recurring: a crystallised complex's co-crystallisation ligand need not be the most potent compound known against that target, while ChEMBL's curation favours published medicinal-chemistry series that report their best analogues. At 12 of 13 targets overlapping, the large majority of this project's labels agree with an independent source; the PDBBind/crystallography-versus-ChEMBL/medicinal-chemistry divergence is real but occasional, consistent with the single occurrence found in the four-target check and the same single additional occurrence found here.

@sec Direct Mechanistic Trace of the Guidance Nudge

Sections E.2 to E.4 establish, over 8 checkpoints and every mechanism-level intervention this project could construct, that the independently computed docking null is not explained by predictor quality, training recipe, representation, or the difficulty of the generalisation test. This section asks the question the earlier sections cannot: what actually happens, step by step, to one molecule's atoms when the gradient is applied? If hypothesis (c) of Section IX.2.3 is correct — that position-only guidance is too weak or too blunt an intervention on a denoiser that was never trained to expect it — a direct trace of the sampling trajectory should show the mechanism by which the nudge fails to matter, not merely confirm, again, that it does not.

@sub Method

One molecule was sampled twice from bit-identical starting noise and identical per-step stochastic draws (the random seed was reset immediately before each call), once unguided (λ = 0) and once guided (λ = 1.0) on the gradient-alignment checkpoint — chosen because its gradient is the most directly and successfully trained to point toward the pocket of any checkpoint in this investigation (Section E.2.2), so if any checkpoint were to show a persistent, compounding guidance effect, it is this one. Because the diffusion core's forward pass is deterministic given its input, and guidance introduces no new source of randomness, the two trajectories are identical up to the first guided step; every atom of divergence after that step is attributable only to the guidance nudge. New instrumentation (`guided_sampling.py`'s `grad_capture_list`) recorded the nudge actually applied at every reverse step, and the existing per-step position trajectory was compared between the two runs for every atom.

The gap starts at exactly zero, grows smoothly rather than flat or oscillating, and accelerates sharply only in the final third of sampling ({tab:futrace}, {fig:futracegap}). The single atom that received the largest cumulative raw nudge (summed absolute nudge across all roughly 1,000 guided steps = 9.49, in the guidance model's own gradient units) ends the trajectory only 0.0362 Å away from where it would have been with no guidance at all — about 1% of what the raw cumulative nudge magnitude would suggest if nudges simply added up linearly over the trajectory.

@fig futracegap | guidance/example_render/trace_gap_plot.png | 5.6 | Mean all-atom position gap between the guided (λ=1.0) and unguided (λ=0) trajectory, by reverse-diffusion step, for the paired deterministic trace of Section E.5. The gap is exactly zero until guidance is first applied, grows smoothly, and only accelerates in the final third of sampling.

This is a specific, falsifiable mechanistic account, not merely "the effect is small". At each reverse-diffusion step, the posterior sampling step adds its own intrinsic stochastic noise, scaled by the DDPM schedule's posterior variance, which is large early in sampling (high raw timestep) and shrinks toward the end. Early in sampling, this intrinsic noise is large relative to the fixed-size deterministic guidance nudge, so the nudge is statistically buried in noise the model would have injected regardless of guidance — consistent with the near-zero gap through roughly the first 80% of sampling in {tab:futrace}. Only as the schedule's posterior variance shrinks toward the end does the same-sized nudge's relative contribution grow enough to produce a measurable, compounding effect — consistent with the late-trajectory acceleration observed. The observed trajectory is consistent with the guidance nudge being largely overwhelmed by the sampler's stochastic noise during most of the trajectory, rather than being systematically cancelled by an opposing correction. This directly supports hypothesis (c) of Section IX.2.3 in a specific form: position-only guidance is weak not because its direction is wrong, but because its magnitude is small relative to the sampler's own injected noise for most of the trajectory.

@sub A puzzle checked, not glossed over

Despite the tiny geometric gap in this molecule (at most 0.13 Å for any of its atoms; the following subsection shows this bound is not general), the two runs' final reconstructed molecules have completely different SMILES, both single-fragment and both chemically valid ({fig:futracemols}). This was checked rather than assumed away. The most likely explanation is that atom-type sampling (a Gumbel-max argmax over discrete logits, a decision-boundary-sensitive operation by construction) is sensitive to even this small a position-driven perturbation at some intermediate step, after which the coupled position-and-type forward pass diverges far more in the discrete channel than in the continuous one that {tab:futrace} measures — a "butterfly effect" specific to discrete sampling, not evidence that the position-level effect was itself large. The specific step at which the type-sampling decision flips was not isolated, and this detail is flagged as open rather than claimed as settled. {fig:futraceunguided} and {fig:futraceguided} render the two molecules of this pair in their docked 3D binding context, the same pair whose 2D structures and position trajectory are given in {fig:futracemols} and {tab:futrace}.

@sub Scope and what would have rejected this hypothesis

This is a mechanistic case study of one molecule, one checkpoint, one guidance strength — it demonstrates a concrete, falsifiable phenomenon and does not by itself make a population-level statistical claim; that evidence is Section E.6's pooled correction. Had the gap instead grown to a large fraction of the raw cumulative nudge (multiple Ångströms, comparable to the summed nudge magnitude of 9.49) while the molecule remained chemically valid, that would have pointed to the guidance direction itself being the problem — a persistent, uncancelled push in a direction that simply does not help Vina Dock — rather than the injection mechanism. That is not what was observed: the gap stays two orders of magnitude below the raw nudge sum throughout, a result consistent specifically with the injection-mechanism hypothesis stated in advance, not merely consistent with "nothing happened".

Three limits of this trace are stated explicitly, because each bounds a different conclusion that a reader might otherwise draw from it. First, *n* = 1 establishes that the phenomenon occurs, not how often or how typically it occurs: this trace is an existence demonstration, and no rate, mean or distribution of the per-step gap over molecules, pockets or seeds is claimed from it. Tracing tens of molecules per pocket and reporting that distribution is the natural next step and was not run here; until it is, any statement of the form "the nudge is typically buried in the sampler's noise" should be read as a hypothesis this single trace is compatible with, not as a measured population property. Second, and relatedly, a small guided-versus-unguided gap is compatible with *several* underlying dynamics, not only with the nudge being overwhelmed by the sampler's intrinsic step noise: a gradient that is small, one that is inconsistent in direction across steps, and one that is actively counteracted by the denoiser would all leave a small terminal gap. Distinguishing them requires intervening on the stochastic component itself, for example by re-running the identical trace under a reduced or zeroed noise schedule and tracking the deterministic and stochastic contributions separately, which this appendix did not do. The noise-overwhelming account is therefore the hypothesis this trace was designed to test and failed to reject, not a mechanism it isolates causally. Third, guidance here acts on atomic positions only; the atom-type channel is never steered directly (Section III.3.2), yet atom types can still change between the two runs through their coupling with the positions inside the denoiser, which is precisely the discrete identity change noted above. The positional trace therefore does not account for the full difference between the two molecules, and the magnitude of the type-channel movement, for instance as a divergence between the two runs' atom-type logits, was not measured.

@sub Was that molecule representative? The same trace over 24 molecules

The account above rests on one molecule, and the paragraph that closes it states a condition under which the opposite conclusion would have followed. That makes the question of whether the molecule was typical a testable one rather than a rhetorical one, so it was tested: the identical paired-deterministic protocol, the same checkpoint, the same pocket and the same guidance strength were run over 24 molecules, varying only the seed, which varies the starting noise, the per-step stochastic draws and the sampled atom count together.

The typical molecule behaves as the case study described, and the spread around it does not. The median mean-gap is 0.0158 Å and the median gap is 0.77% of the cumulative nudge per atom, both close to the case study's reading. But the range runs from 0.0050 to 0.4361 Å, a factor of 87, and 8 of the 24 molecules end above 1% of the cumulative nudge, seven of them between 4.7% and 28.5%. The largest single-atom displacement observed is 1.68 Å, against the 0.13 Å of the case study. The molecule traced in the previous subsection sits at about the 70th percentile of this distribution: not an outlier, but above the middle, and in no sense a bound.

Three statements are therefore revised. "Two orders of magnitude below the raw nudge sum" and "at most 0.13 Å for any atom" describe that molecule and are withdrawn as general claims; they hold for the median molecule but not for roughly a third of them. The third revision is the consequential one. The case study's closing paragraph pre-stated that a gap growing to a large fraction of the raw cumulative nudge, while the molecule remained chemically valid, would have pointed at the guidance *direction* rather than at the injection mechanism. In 8 of 24 molecules the geometric half of that condition is approached, and in the most extreme the nudge is plainly not being overwhelmed at all. The chemical-validity half was not measured in this run, so the pre-stated condition is not claimed to be met in full; what can be said is that the injection-mechanism account describes the typical molecule and not the population.

That revision strengthens the thesis's reading rather than unsettling it, and the reason is worth stating explicitly. In the molecules where the nudge is *not* swamped, where atoms move by a substantial fraction of the accumulated push, the independently computed docking score still does not improve: those molecules are drawn from the same pools whose docking null is reported in Chapter V and Appendix E.2. A guidance signal that moves atoms appreciably and still produces no docking benefit is evidence about the signal, not about the mechanism carrying it, which is the F1 reading of Chapter III. It converges with the signed-direction measurement of Section V.4, which found the gradient's direction indistinguishable from random over 23,202 atom-states. Two independent measurements, one of where the gradient points and one of how far it actually moves atoms, now agree that the limitation lies in what the predictor knows rather than in whether its gradient reaches the sampler.

@sec What This Appendix Adds to the Thesis's Central Claim

Chapter IX's hypotheses (a) and (c) — that the clean/noisy training mismatch, and the weakness of position-only guidance, might explain the null result — were both, at the time that chapter was written, untested and flagged as outside the compute budget available. Both were tested directly in this appendix. Hypothesis (a) does not explain the null: a predictor trained on exactly the noise distribution it will see at inference (Section E.2.1), and a predictor given an entirely new, non-noise-related information source (ESM2, Section E.2.3), both leave the pattern unchanged. Hypothesis (c) is directly supported, in a specific mechanistic form, by the trace of Section E.5: the position-only nudge is small enough, for most of the sampling trajectory, to be statistically buried in the sampler's own intrinsic step noise, and only compounds to a measurable but still sub-Ångström effect in the final steps, where it is large enough to flip discrete atom-type decisions without being large enough to move the docking score in a defensible, reproducible way. The two independent validation branches of Phase 2 (PLIP interaction counts, Section E.3.1; the unseen-protein-family generalisation test, Section E.3.2) rule out two further alternative explanations: that Vina Dock hides an interaction-level effect, and that the null pattern is an artefact of every tested pocket belonging to a protein family the predictor had already seen. None of this changes Chapter IX's central conclusion. It replaces two previously untested hypotheses with a tested, mechanistically specific account of why position-only gradient guidance on a frozen, pretrained diffusion model does not produce a defensible improvement under the conditions this project could test, and it rules out the two most plausible ways that conclusion could have been an artefact of the predictor, the evaluation metric, or the generalisation difficulty of the test set.
