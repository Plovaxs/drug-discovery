# Stage 2+ Experiment Log

Single source of truth for this phase (Track A: PIGNet2 physics anchoring;
Track B: alternative guidance-mechanism exploration). Updated after every
sub-experiment, exploratory and full tier alike. Narrative documents are
derived from this table, not the other way around.

Every checkpoint from this phase applies BOTH a predictive-quality
criterion and the gradient-informativeness test (KS test on real Vina
Dock distributions, guided vs. unguided, Benjamini-Hochberg corrected
across all tests run within one checkpoint) — see
`guidance/FLAGSHIP_ARCHITECTURE_RESEARCH.md`'s Stage 2+ addendum for the
full protocol specification.
